# Atender v9.1 — Density Tighten + Self/Room Timetable 統一

作成日: 2026-05-28
ベース: v9 (`20260528-v9-timetree-rework.md`)
スコープ: **UI/Token のみ**。Backend / Prisma / 機能仕様すべて据え置き。

---

## 0. Executive Summary

v5 で導入した「Major Third (1.25)」タイポと「8pt grid (large)」余白が、モバイル (375×800dvh) viewport で
chrome (TopBar 56 + BottomTab 80 + section gap 32 ×N) に占有され、本体時間割が viewport 残り 250-300px に
押し込まれている。Touri 体感では「TimeTree / Cloudflare Dashboard / Linear / Notion Calendar
レベルの密度に持っていきたい」「自分とルームの時間割部品も統一したい」。

本設計は **既存機能を一切変えず**、以下を実施する。

1. **タイポを Minor Third (1.20) + base=14px に圧縮** (text-base 16→14, text-xl 25→20 等)
2. **Spacing semantic を一段詰める** (page-px 20→12, card 20→12, section-gap 32→16)
3. **TopBar 56 → 48 / BottomTab 80 → 64** で chrome 28px 削減 (合計 -24px、% で約 7-10% 解放)
4. **共通コンポーネント `EventTile` を新設**し、自時間割 (DayMeetingCard / MeetingBlock) と
   ルーム時間割 (RoomTimetable / CalendarDay / CalendarWeek / CalendarMonth dots) をすべて移行
5. **Home の時間割タブで `TimetableGrid` を mobile でも使う形に切り替え**、`100dvh - chrome` を
   grid に直接当てて「ほぼスクロールなしで 1 画面に時間割が収まる」状態を CSS で保証する
6. **PeriodLabel 列幅 56 → 44px** + cell padding 切り詰めで grid 全体の密度を 30% 上げる
7. v9 で確定した **5 タブ / Home dispatcher / SemesterOverview / Course Suspension は構造維持**

### 主要判断 5-7

| # | 判断 | 根拠 |
|---|---|---|
| 1 | base font-size を 14px に下げる | TimeTree iOS の event font は 12-13px、Cloudflare Dashboard body は 13-14px。日本語 Noto Sans JP は 14px でも視認性確保可。Touri 要望「モバイルファースト」に合致 |
| 2 | Minor Third (1.20) 採用 | Major Third (1.25) は見出しが太く詰まりすぎる。1.20 は Linear / Stripe のスケール。階層は残しつつ縦圧縮 |
| 3 | `EventTile` 共通化 | 4 箇所 (DayMeetingCard / MeetingBlock / RoomTimetable / CalendarDay) で同じ「tint bg + 左 pill + title + subtitle」を別実装。density 軸 `compact` / `comfortable` で吸収 |
| 4 | TimetableGrid を mobile で **常時** 表示 | v9 まで `md:hidden` で DayList / `hidden md:block` で TimetableGrid だった。Touri 要望「自分の時間割もスクロールなしで見える」を満たすには 5×5 grid 表示が必須 |
| 5 | DayList は **撤去せず温存** | week view fallback で既に使われ、`viewMode==='day'` のときは「TimeTree 日選択」UX を提供。本設計では「Home 時間割タブ default を 5×5 grid」「日選択は別タブ (calendar mode で代替)」に変更 |
| 6 | section gap を mobile=16 / desktop=24 に半減 | 32px は SwiftUI HIG では `xxLarge`。8pt grid 維持しつつ `large` (16) を section default に降格 |
| 7 | BottomTab を 64px に縮める | アイコン 24→20、label 10px、tap target 44pt min は保持 (icon button 自体は 40×40)。HIG 44pt min cleared |

| token | 旧 (v5 Major Third) | 新 (v9.1 Minor Third + base=14) | 用途 |

| `--leading-snug` | `1.2` | `1.2` | 変更なし |

| `--leading-body` | `1.5` | **`1.4`** | body 行間圧縮 |
| `--leading-relaxed` | `1.6` | `1.5` | わずか圧縮 |

実装上の注意:

- `html { font-size: 16px }` を `font-size: 14px` に変更する **だけ**で Tailwind 全 `text-*` クラスが
  rem ベースで縮む (Tailwind v4 はデフォルト rem 単位)。`--text-*` トークンは `px` で明示しているため
  二重に効かない (= `text-base` を使った場合のみ html 基準 14px が効く、`text-[14px]` 等のハードコード
  は別途見直し)。
- ハードコード `text-[N]px` は **既存ファイル内のものを変更しない** (各 component 内で意図された数値)。
  ただし v9.1 で更新が必要な component (後述 §3) は適宜縮める。

### 2.2 Props

```typescript
export type EventTileDensity = "compact" | "comfortable";

export type EventTileProps = {
  /** タイトル (1-2 行 line-clamp、必須) */
  title: string;
  /** 識別カラー (course.color or member.color 等。必須) */
  color: string;
  /** サブタイトル (room / teacher / memberName 等、optional) */
  subtitle?: string | null;
  /** 補助ラベル (時刻 etc、optional、subtitle と別行で表示) */
  meta?: string | null;
  /** 表示密度。compact=ルーム時間割 cell / comfortable=自時間割 day card */
  density?: EventTileDensity; // default: "compact"
  /** 左 pill 表示の有無 (default: true) */
  showPill?: boolean;
  /** クリック時の callback。指定時のみ <button>、無指定時は <div> */
  onClick?: () => void;
  /** 先頭に並ぶアイコン (Google / ICS マーク用) */
  leadingIcon?: ReactNode;
  /** label 左 / cell 右側に並べる「期/限ラッパー」差し込み (DayMeetingCard 互換) */
  badge?: ReactNode;
  /** 固定 height (RoomTimetable のような % 計算で渡す。指定時は min-height ではなく height) */
  height?: string | number;
  /** aria-label override */
  ariaLabel?: string;
  /** 追加 className (位置調整等。bg/color/padding は内部で完結) */
  className?: string;
  /** root style (position absolute / top % / left % 等、計算系で必要時のみ) */
  style?: CSSProperties;
};
```

### 2.3 内部実装方針

```tsx
function EventTile(props: EventTileProps) {
  const density = props.density ?? "compact";
  const showPill = props.showPill ?? true;
  const subColor = `color-mix(in srgb, ${props.color} 70%, var(--event-mix-target))`;
  const tint = `color-mix(in srgb, ${props.color} 15%, var(--color-bg-elevated))`;

  const pad = density === "compact" ? "px-2 py-1" : "px-2.5 py-1.5";
  const pillInset = density === "compact" ? "left-1 top-1 bottom-1" : "left-1.5 top-1.5 bottom-1.5";
  const pillWidth = density === "compact" ? "w-0.5" : "w-1";
  const titleSize = density === "compact" ? "text-[12px]" : "text-[13px]";
  const subtitleSize = density === "compact" ? "text-[10px]" : "text-[11px]";
  const radius = "rounded-md"; // 8px、v5 の 12px から圧縮

  const Wrapper = props.onClick ? "button" : "div";
  return (
    <Wrapper
      type={props.onClick ? "button" : undefined}
      onClick={props.onClick}
      aria-label={props.ariaLabel}
      className={`relative block w-full overflow-hidden ${radius} text-left transition active:scale-[0.99] ${props.className ?? ""}`}
      style={{ background: tint, height: props.height, ...props.style }}
    >
      {showPill ? (
        <span
          className={`absolute ${pillInset} ${pillWidth} rounded-full`}
          style={{ background: props.color }}
        />
      ) : null}
      <div className={`flex h-full items-center gap-2 ${pad} ${showPill ? "pl-3" : ""}`}>
        {props.badge ?? null}
        <div className="min-w-0 flex-1">
          <p className={`line-clamp-2 ${titleSize} font-semibold leading-tight text-fg-primary`}>
            {props.leadingIcon ? <span className="mr-1 inline-flex align-middle">{props.leadingIcon}</span> : null}
            {props.title}
          </p>
          {props.subtitle ? (
            <p className={`mt-0.5 truncate ${subtitleSize} font-medium`} style={{ color: subColor }}>
              {props.subtitle}
            </p>
          ) : null}
          {props.meta ? (
            <p className={`truncate ${subtitleSize} leading-tight text-fg-tertiary`}>{props.meta}</p>
          ) : null}
        </div>
      </div>
    </Wrapper>
  );
}
```

仕様:
- **`TimetableGrid` を mobile でも使う**。`md:hidden` / `hidden md:block` の出し分けは廃止

- TimetableGrid 内部は **min-width を撤去**し、残 viewport に grid を fit させる:
  - `grid-cols-[44px_repeat(5,minmax(0,1fr))]` (旧 `56px_repeat(5,minmax(110px,1fr))`)

- `Settings` ボタン (歯車) は **`HomeSemesterPicker` 行の右端に inline 配置**。v9 は別行で `flex justify-end` していたが、これで 56px 削減 (h-11 + space-y-3 ≒ 56)

iPhone SE: 667 - 352 = **315px** が grid 領域

これを `header row (28px) + 5 rows × ?` に当てる:
- header 28px → grid 残: 287px
- 5 rows → 各 row = 57px

iPhone 14 mini (812px): 812 - 352 = 460px → 各 row 86px (余裕あり)

## 8. 不採用案

### 8.1 「自分の時間割は DayList のまま、Room だけ Grid」
- ❌: Touri 要望「統一感」に反する
- ❌: DayList は 1 日分しか見えず情報量で TimeTree に負ける

### 8.2 「フォントを 12px base まで下げる」
- ❌: 日本語 (Noto Sans JP) で 12px は限界。Apple HIG (iOS) 推奨は body 13pt 以上 (= 13px 程度)
- ❌: 弱視・40 代以上に厳しい (Atender ターゲットは学生だが家族画面共有も視野)
- 採用: **14px base** で TimeTree iOS (12-13 px event font) と Cloudflare Dashboard (13-14px body) の中間

### 8.3 「CSS subgrid で grid を入れ子に」
- ❌: Safari 16 以前で subgrid 未対応。Atender は iOS 15+ 想定なのでサポートできない
- 採用: 単一 grid で `grid-template-rows: 28px repeat(5, minmax(0, 1fr))`

### 8.4 「BottomTab を 56px (Material Design 標準)」
- ❌: iOS HIG では tab bar 49pt + safe area。56px は中途半端で iOS らしさが消える
- 採用: **64px** (content 48 + safe-area 余白)。`tab-bar-content: 48` で内部高さ管理

### 8.5 「TopBar 廃止、context chip を最上段に」
- ❌: ブランド露出 (atender ロゴ) と歯車アクセスを失う。SignIn 等で別 layout が必要に
- 採用: TopBar は h-12 (48px) に縮めて存続

### 8.6 「DayMeetingCard の期数大型 badge を撤去して密度爆上げ」
- ❌: 期数は時間割の主軸情報。v9 で導入した「左 P 数字」は Penmark / TimeTree 比でも独自性
- 採用: badge を EventTile の `badge` slot として残し、density=comfortable でのみ表示

### 8.7 「Home 時間割タブで TimeTableGrid + DayList を切替表示」
- ❌: viewModeTabs (時間割/カレンダー) と機能重複。3 軸タブは初心者を迷わせる
- 採用: 時間割タブ = TimetableGrid (5×5 週表示) 固定、日表示が欲しければカレンダー → 日 view へ

### 8.8 「TanStack Query の cache 構造を変える」
- ❌: 本設計の対象外 (UI/Token のみ)
- 採用: hooks / cache key 一切変更しない

## 12. リスクと対応

| リスク | 対応 |
|---|---|
| html font-size を 14px に下げたら、外部 component (lucide-react など) の icon サイズが狂う | lucide-react は `h-N w-N` で px ベース、影響なし。Tailwind v4 は rem ベースで全 `text-*` `gap-*` `space-*` `h-*` `w-*` などが 14/16 倍に縮む → これは設計の意図する効果 (全体ダウンサイズ) |
| `text-[N]px` のハードコードが残って二重サイズ | 既存ハードコード `text-[12px]` `text-[10px]` 等は **px 直値なので html font-size 変更の影響を受けない**。本設計で言及した数値変更だけ反映 |
| BottomTab 64px で 12 タブ並べたら詰まる | 5 タブ (v9 確定) なので問題なし。各タブ幅 75px |
| TimetableGrid 1 画面表示で長い course name が 2 行 + truncate でも溢れる | EventTile は line-clamp-2 + overflow hidden。subtitle / meta は truncate 単行。最悪は文字が見切れるが、tap → MeetingDetailSheet で全表示 |
| iPad 縦持ち (768px) でも mobile レイアウト相当になる | Tailwind `md:` は 768px 以上を含む。iPad は md+ なので PC レイアウト (SideNav + より広い max-w) に切り替わる。本設計の影響なし |
| Touri が後で「やっぱり pct を 61px に戻して」と言う場合 | `--text-5xl` は token 1 行で再変更可能 |
